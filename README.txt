# Photoroom by Robitech

This extension is protected with a subscription license system.

After the extension is added to the browser, it will ask the user for a valid license key. When the user enters the license key, the extension sends the key to the official license server for validation. If the server confirms that the license is valid, the extension becomes active.

After successful validation, the main extension features are loaded through the browser from the server and the extension starts working normally. Without a valid license, the extension will not unlock its full features.

This extension may also check subscription status, remaining license time, available credits, and server-side updates when needed.
